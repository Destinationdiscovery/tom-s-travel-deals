

# Create Universal SEO Knowledge Base

## Problem
The previous KB was written specifically for ReviewThenGo. You want a **universal** SEO knowledge base that applies to any project, campaign, or website — so every future AI interaction across any project benefits from these 2026 best practices.

## Approach
Create `.lovable/seo-knowledge-base.md` as a project-agnostic reference. All 10 entries will use generic language, universal examples, and framework-style guidance that works for any site — travel, ecommerce, SaaS, portfolio, etc.

## File

| File | Action |
|------|--------|
| `.lovable/seo-knowledge-base.md` | NEW: 10 universal KB entries |

## Structure

Each entry follows this format:
- **Framework**: What it is (2-3 sentences)
- **When to Apply**: Project types and scenarios where this matters
- **Implementation Checklist**: 3-5 actionable steps (generic)
- **Example**: One concrete example showing the pattern

### Entries (all generic, not site-specific):

**Critical:**
1. Content Hub Architecture — pillar + cluster pages with bidirectional linking
2. Intent-Based Content Mapping — matching search intent types to page types
3. EEAT Signal Layering — author bios, citations, original data, trust indicators
4. Query Fan-Out Mapping — semantic variations and follow-up question coverage

**High-Value:**
5. Semantic LSI Keyword Integration — contextual related terms throughout content
6. Content Freshness Audit Protocol — scheduled updates, data refresh, link checks
7. Schema Markup for Knowledge Bases — BreadcrumbList, SearchAction, Person, NavigationElement
8. AI Search Referral Tracking — attribution for GPTBot/Perplexity/Claude traffic

**Emerging:**
9. Brand Coherence Across Touchpoints — consistent positioning across all channels
10. Corpus of Content Model — focus on 50-200 core pages vs. infinite content creation

No ReviewThenGo-specific references. Pure framework guidance any project can use.

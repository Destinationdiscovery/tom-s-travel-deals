

## AI Review Overhaul: Photos, Things to Do, Layout Rebalance

### What's Changing

This is a significant upgrade to the AI-generated review experience across five areas:

1. **Photo gallery** with professional destination photos that open in a full-screen lightbox when clicked
2. **"Things to Do" section** with 3 highlighted activities and booking CTAs
3. **Desktop layout rebalanced** -- sidebar gets more content so it doesn't look empty
4. **Mobile content order optimized** -- booking links and "new search" button moved to the bottom where they belong
5. **Visual consistency** -- all sections follow the same card styling as the rest of the site

---

### Where Photos Come From

The project already has a Google Places API key configured. When an AI review is generated, the backend will also search Google Places for the property/destination, retrieve up to 6 professional photos, and include them in the review. A separate backend function will serve the photos securely without exposing the API key.

For cached reviews that were already generated (before this update), the photo gallery simply won't appear -- no errors, just gracefully hidden.

### Things to Do Section

3 activity cards generated by AI, each with:
- Activity name (e.g., "Hornblower Niagara Cruises")
- Short description (1-2 sentences)
- Category tag (e.g., "Adventure", "Dining", "Culture")
- A "Book on Expedia" CTA button using the geo-targeted affiliate links

A "See More Activities" link will also appear, pointing to the Expedia affiliate link.

### Technical Details

**File 1: `supabase/functions/generate-review/index.ts`** -- Enhanced edge function

- Add `thingsToDo` to the Perplexity prompt, requesting 3 activities with `name`, `description`, and `category` fields
- After Perplexity returns, call Google Places Text Search API (`places.googleapis.com/v1/places:searchText`) to find the place
- Extract up to 6 photo resource names from the response
- Store photo names in `review_data.photoReferences` array
- Store things to do in `review_data.thingsToDo` array

**File 2: `supabase/functions/place-photos/index.ts`** -- New proxy edge function

- Accepts a `name` query parameter (Google Places photo resource name)
- Calls `places.googleapis.com/v1/{name}/media?maxWidthPx=800` with the API key server-side
- Returns the image data directly (acts as an image proxy)
- Keeps the Google API key hidden from the frontend

**File 3: `src/hooks/useGenerateReview.ts`** -- Update TypeScript interfaces

- Add to `ReviewData`:
  - `thingsToDo?: Array<{ name: string; description: string; category: string }>`
  - `photoReferences?: string[]`

**File 4: `src/components/AIReviewResult.tsx`** -- Major layout overhaul

- Restructure the entire grid layout for desktop (left content + right sidebar)
- Add CSS ordering classes for mobile reflow (`order-1` through `order-9` on `lg:order-none`)
- **New: Photo Gallery section** -- 2x3 grid (2 columns on mobile) of clickable thumbnails that fetch images from the `place-photos` edge function; clicking opens the existing `ImageLightbox` component
- **New: Things to Do section** -- 3 cards in a row (stacked on mobile) with activity name, description, category badge, and geo-targeted Expedia CTA button
- **Move to sidebar**: Location Map, Affiliate Links (Book or Compare Prices), and Search Another Property button
- All new sections use existing card styles (`bg-card rounded-2xl p-6 shadow-soft`) for visual consistency

**No database changes needed** -- `review_data` is already a flexible JSONB column that accepts any structure.



## Save and Compare Reviews

Let users bookmark up to 5 AI-generated reviews and then run an AI-powered head-to-head comparison.

### How it works

1. After a review loads, a **"Save to Compare"** button appears alongside the existing "Search Another Property" button
2. A small **floating badge** in the bottom-right corner shows how many reviews are saved (e.g., "2/5 saved") and links to the comparison page
3. When 2+ reviews are saved, the badge also shows a **"Compare Now"** button
4. The **/compare** page displays all saved reviews side-by-side with ratings, summaries, and an AI-generated professional verdict

### Storage approach

- **localStorage** -- no login required, works immediately
- Reviews are stored as lightweight objects (name, location, slug, overall rating, ratings breakdown, summary, best-for tags)
- Max 5 saved reviews; trying to add a 6th shows a toast asking to remove one first

### Comparison page layout

- **Header**: "Your Comparison" with saved property count
- **Side-by-side cards** (horizontal scroll on mobile): Each card shows property name, location, overall rating, rating bars, best-for tags, and a short summary
- **Rating comparison table**: All rating categories in rows, properties in columns, with the highest value highlighted
- **AI Verdict section**: A professionally written comparison generated by Lovable AI (Gemini Flash), covering which property wins in each area and an overall recommendation
- **Actions**: "Remove" button on each card, "Clear All" button, "Back to Search" link

### Technical details

**`useSavedReviews` hook**
- Reads/writes to `localStorage` key `rtg_saved_reviews`
- Exposes: `savedReviews`, `addReview(review)`, `removeReview(slug)`, `clearAll()`, `isSaved(slug)`, `canAddMore` (boolean, true if < 5)
- Dispatches a `storage` event so other components react to changes

**`compare-reviews` edge function**
- Accepts the array of saved review data (ratings, summaries, names)
- Calls Lovable AI (`google/gemini-3-flash-preview`) with a prompt to produce a structured comparison
- Uses tool calling to return structured JSON: winner per category, overall recommendation, and a 2-3 paragraph written verdict
- Handles 429/402 rate limit errors gracefully

**`SaveReviewButton`**
- Toggles between "Save to Compare" (outline style with bookmark icon) and "Saved" (filled style with check icon)
- Shows a toast on save ("Saved! 2/5 -- Compare when ready") and on remove
- Disables with tooltip when 5 are already saved and this one isn't among them

**`ComparisonFloatingBadge`**
- Only visible when 1+ reviews are saved
- Shows count badge and animates in/out
- "Compare Now" link navigates to `/compare`
- Positioned bottom-right, above the scroll indicator
